Blockworld Bridge

마크 서버 · 맵 · relay · 모듈 준비

Minecraft 1.21.4

서버 준비

마인크래프트 1.21.4 서버를 이 PC에 설치합니다. 한 번만 하면 됩니다.

  1. Java 21 확인

    1.21.4 서버는 Java 21 이상으로 실행됩니다. 없으면 Java 자동 설치를 누르세요. 앱 폴더에만 설치되고 PC의 다른 Java 는 건드리지 않습니다.

  2. 서버 종류 고르기

    잘 모르겠으면 Paper를 고르세요. 바닐라와 같은 게임이면서 더 가볍습니다.

  3. EULA 동의

    서버를 실행하려면 Mojang 의 최종 사용자 사용권 계약(EULA)에 동의해야 합니다. 앱이 대신 동의하지 않습니다. 읽어 본 뒤 직접 체크하세요.

  4. 서버 받기

    고른 종류의 서버 파일을 공식 주소에서 받고 체크섬을 확인합니다. 종류를 바꾸면 다시 받으세요.

맵

서버가 열 월드를 정합니다. 가져온 맵은 앱 폴더로 복사되고 원본은 그대로 남습니다.

  1. 가진 맵 넣기

    싱글플레이 월드는 %appdata%\.minecraft\saves\월드이름 폴더입니다. 받은 맵은 zip 그대로 넣어도 됩니다. 가져온 맵은 바로 선택됩니다.

    여기에 월드 폴더나 zip 을 끌어다 놓기

  2. 또는 새 맵 만들기

    서버를 처음 켤 때 만들어집니다. 평면은 모듈 시험에 좋고, 일반은 보통 생존 지형입니다.

  3. 사용할 맵 고르기

    서버 폴더에 있는 맵입니다. 1.21.4보다 새 버전으로 저장된 맵은 열 수 없습니다.

    설정

    고르면 저장되고, 마지막의 설정 적용을 눌러야 서버와 relay 파일에 써집니다. 토큰과 RCON 비밀번호는 자동으로 만들어 양쪽에 똑같이 넣습니다.

    1. 접속 방식

      어느 쪽이든 서버는 이 PC(127.0.0.1)에서만 열리고 밖에서는 접속할 수 없습니다.

    2. 성능 프리셋

      Foundry 로 보내는 3D 범위와 지도 갱신 빈도입니다. 플레이어가 많거나 PC가 느리면 가볍게.

    3. 서버 메모리

      PC 메모리가 8GB 면 2~3GB, 16GB 이상이면 4GB 를 권합니다.

      GB

    4. 포트 (보통은 그대로)

      다른 마크 서버가 이미 켜져 있을 때만 바꾸세요.

    5. 설정 적용

      server.properties 와 relay 설정을 씁니다. 캐릭터가 스폰 근처에서도 블록을 캘 수 있도록 스폰 보호도 끕니다.

    모듈 설치

    이 앱에 들어 있는 Blockworld Bridge 모듈을 이 PC의 Foundry 에 설치합니다.

    1. Foundry 데이터 폴더 지정

      Foundry 설정의 사용자 데이터 경로 안에 있는 Data 폴더입니다. 바꾼 적이 없다면 기본 위치 사용을 누르세요.

    2. 설치 · 업데이트

      모듈 폴더만 바꿉니다. 월드와 3D 텍스처(bwb-assets)는 그대로 둡니다. Foundry 가 켜져 있었다면 설치 뒤 Foundry 를 다시 시작하세요.

    3. Foundry 에서 할 일

      1. 월드를 열고 설정 → 모듈 관리에서 Blockworld Bridge 켜기
      2. 설정 → 모듈 설정에 실행 탭의 주소와 토큰 붙여 넣기, 자동 연결 켜기
      3. 토큰 컨트롤의 🧊 버튼(Shift+M)으로 패널 열기

    실행

    서버를 켜고, 준비되면 relay 를 켭니다. 그다음 Foundry 를 따로 실행하세요.

    1. 시작 · 정지

      정지하면 relay 를 먼저 끄고 서버에 stop 을 보내 맵을 저장한 뒤 끕니다. 창을 닫아도 같은 순서로 끕니다.

    2. Foundry 에 넣을 값

      모듈 설정의 중계 서버 주소와 토큰에 그대로 붙여 넣으세요. 토큰은 설정 적용 때 한 번 만들어지고 바뀌지 않습니다.
